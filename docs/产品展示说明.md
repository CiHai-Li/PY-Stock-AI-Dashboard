# 产品展示说明

## 面试演示路径

1. 进入数据质检：导入本地授权的JSON样本。区分财务字段可用、财务异常、评分字段待补。展开记录来源可查看口径、可获得日期和披露日期缺失提示。
2. 进入财务分析：核验净利率、现金利润比、负债率和对应报告期。展示缺失市场字段时不强行生成综合分；展开因子设置可以调整权重并查看启发式规则。
3. 展示同期与同业分析：上年同季度且口径一致才能计算同比。缺少上年数据或同业样本时明确提示，不把未知写成0。
4. 进入信号校准：默认历史样本为虚构数据。说明期初扣费、末期平仓、初始净值、日终回撤及基准比较口径。真实数据需按单标的导入，停牌执行不在当前模型支持范围。
5. 进入解释与审核：当前分析整理为证据后，可调用配置的大模型服务。逐条绑定验收答案断言与原始证据，完成四维评价后批准并导出。修改任一证据、答案或数据参数，旧批准自动失效。

## 数据边界

演示样本和产品功能不能证明商业化使用规模、企业提效比例或预测能力。论文下载样本只用于本地核对，不属于公开仓库数据。缺少披露日期的数据不能证明历史时点可得；没有合格历史收益与信号时不展示为真实回测。

## 关键取舍

数值计算与模型解释分开。财务校验与评分资格分开。人工确认与程序结构校验分开。字段完整度不是可信概率，启发式评分不是交易指令。
