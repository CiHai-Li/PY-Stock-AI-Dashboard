# PY股票AI操作盘 产品展示说明

## 一句话定位

PY股票AI操作盘是一款强调“证据、校准和风险边界”的股票研究助手，将行情、财务和新闻信息转化为可核验的结构化结论。

## 为什么重新设计

常见 AI 股票分析产品功能很多，却容易出现三个问题：模型直接生成分数、置信度没有统计校准、单股建议缺少组合风险约束。PY股票AI操作盘将数值判断与语言解释分开，让大模型只承担擅长的归纳和表达。

## 产品逻辑

1. 数据层：统一行情、财务和事件口径，记录来源、时间与缺失状态。
2. 评分层：使用固定权重计算质量、趋势、事件和风险保护分。
3. 解释层：AI 根据结构化因子和证据生成可读结论，但不能修改分数。
4. 验证层：用滚动回测展示不同分数段的命中率、收益和最大回撤。
5. 组合层：检查行业集中度、资产相关性、波动率和单日风险价值。

## 面试演示路径

1. 从研究驾驶舱介绍“先给证据，再给结论”的设计原则。
2. 切换不同股票，观察四因子、证据链和数据可信度如何变化。
3. 进入信号校准，说明高分信号必须用历史数据证明有效。
4. 进入组合风险，说明好股票不等于好组合。
5. 强调产品不会自动交易，最终决策权始终属于用户。

## MVP 与商用边界

当前版本使用演示数据，重点验证信息架构、决策链和可视化表达。商用版本还需要接入合规行情、点时数据仓库、真实滚动回测、用户权限、审计日志和模型版本管理。
