# PY股票AI操作盘｜可验证股票研究助手

> 一个把“AI 股票分析”重构为“可验证研究决策”的轻量产品作品。

PY股票AI操作盘面向个人投资研究者和投研团队，聚合行情、财务与新闻事件，但不让大模型直接决定评分。产品用确定性规则计算质量、趋势、事件和风险因子，AI 只负责解释，并通过证据链、数据质量、历史校准与组合风险展示结论边界。

## 产品亮点

| 模块 | 解决的问题 | 产品输出 |
| --- | --- | --- |
| 研究驾驶舱 | AI 结论不可解释 | 四因子评分、证据链、可信度与数据时间 |
| 信号校准 | 评分没有效果证明 | 命中率、超额收益、回撤、夏普和成本 |
| 数据质量 | 多数据源口径不一致 | 完整度、时效性、降级状态与来源边界 |
| 组合风险 | 只看单股忽略整体风险 | 行业集中度、相关风险、波动率与 VaR |

## 相比常见 AI 股票分析项目的精简

- 保留：核心股票研究、技术/基本面/事件分析、可视化报告。
- 精简：复杂机器人推送、多桌面端、多模型路由和大量部署配置。
- 强化：确定性评分、模型版本记录、来源证据、滚动回测和组合风控。
- 边界：这是研究辅助工具，不构成投资建议，也不会自动交易。

## 决策流程

```text
行情 / 财务 / 新闻
        ↓ 数据标准化与质量检查
确定性四因子评分（质量 / 趋势 / 事件 / 风险）
        ↓
证据链与 AI 解释（AI 不修改评分）
        ↓
历史信号校准与组合风险检查
        ↓
导出研究纪要，由用户独立决策
```

## 金融数据与评估实验室

从侧栏进入“数据与评估实验室”，可直接运行以下流程：

- JSON导入：支持1–5000条行情与财务记录，下载模板、编辑样本，设置历史分析时点。
- 数据质量门禁：检查缺失字段、非数值、重复证券报告期、未来信息、过期数据、资产负债异常及单位疑点。问题记录暂停评分，保留原始值供人工复核。
- 财务分析：计算净利率、经营现金流与净利润比、资产负债率，保留数据日期、来源和规则版本。
- 因子实验：质量、趋势、事件与风险保护四项可调权重，自动归一化，重新计算评分并导出完整证据。评分为启发式研究规则，未经真实市场预测能力验证。
- 金融回答评估：输入回答与证据，检查收益承诺、缺少风险提示和证据缺失，导出待审核样本。该流程是规则初筛，不自动断言事实正确，不直接生成可用于训练的已验收SFT数据。

金额字段需统一币种、单位和报告周期。`asOf`为数据实际可获得日期；默认数据为虚构样本，页面中的既有收益、VaR和命中率为预设演示，不是真实回测或实时行情。实验室无需外部API密钥，不会将导入数据发送到远程模型；外部LLM推理可按下方配置启用，默认关闭。

## 金融研究与人工评估流程

在数据与评估实验室或信号校准页中使用：

1. **问题处理**：选择记录序号，载入原始记录，填写修正值和处理原因。系统重新执行全部质量规则；未通过不能完成处理。导出文件包含原始值、修正值、原因、时间与规则版本。这是业务核验依据，不是项目修改日志。
2. **多期分析**：使用 `2026-Q2` 形式的报告期，补充 `currency`、`unit`、`basis`（如半年累计）、`industry` 和 `source`。同比匹配去年同季度及相同口径；同业中位数至少需要三个其他同业样本。点“载入多期财务演示”可验证利润现金流背离提示。
3. **历史校准**：导入日频 `date, signalAsOf, score, assetReturn, benchmarkReturn` JSON。收益使用小数；信号必须在收益日期之前可得。至少30期，包含入场、退出和最终平仓成本，计算净值、基准、超额、回撤、夏普和历史VaR。当前为单标的多头/现金策略，不是多资产组合模拟，也不自动执行训练。默认数据为虚构；由用户自行提供授权的真实历史数据。
4. **模型解释**：服务端读取兼容 Chat Completions 的完整HTTPS地址、API密钥与模型名；浏览器只输入研究服务访问口令，不能获取供应商密钥。生成前由用户主动提交证据，生成答案进入待审核队列。
5. **人工验收**：四维评价（事实、计算、推理、风险）、逐条断言/来源/摘录、错误类型、审核人和修改后的答案全部完成后才可批准。回答或证据变更会使既有批准失效。待审核记录和已验收训练样本分别导出；后者仅代表本工具中审核人的确认，不能替代专家复审或组织级权限审批。

### 模型服务配置

在部署服务环境或本地未提交的 `.env.local` 配置：

```dotenv
RESEARCH_LLM_URL=https://your-provider.example/v1/chat/completions
RESEARCH_LLM_KEY=your-provider-key
RESEARCH_LLM_MODEL=your-model-name
RESEARCH_ACCESS_TOKEN=replace-with-a-random-token-at-least-16-characters
```

未配置时接口返回503；访问口令不符返回401。每个运行实例有5秒请求间隔和30秒模型超时。口令是轻量演示访问控制，生产企业部署仍需统一身份认证、角色权限、集中审计和分布式限流。导入的数据、人工评估和处理记录仅保留在页面内存，刷新前请导出；供应商模型调用会把主动提交的证据发送到配置的服务。不要提交无权对外传输的数据。

数值计算不交给大模型，模型解释也不会自动成为已验收训练数据。项目不内置商业数据授权，不默认联网抓取真实证券数据，不包含企业提效比例验证。
