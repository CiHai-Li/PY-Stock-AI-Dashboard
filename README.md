# 证析 AI｜可验证股票研究助手

> 一个把“AI 股票分析”重构为“可验证研究决策”的轻量产品作品。

证析 AI 面向个人投资研究者和投研团队，聚合行情、财务与新闻事件，但不让大模型直接决定评分。产品用确定性规则计算质量、趋势、事件和风险因子，AI 只负责解释，并通过证据链、数据质量、历史校准与组合风险展示结论边界。

## 产品亮点

| 模块 | 解决的问题 | 产品输出 |
| --- | --- | --- |
| 研究驾驶舱 | AI 结论不可解释 | 四因子评分、证据链、可信度与数据时间 |
| 信号校准 | 评分没有效果证明 | 命中率、超额收益、回撤、夏普和成本 |
| 数据质量 | 多数据源口径不一致 | 完整度、时效性、降级状态与来源边界 |
| 组合风险 | 只看单股忽略整体风险 | 行业集中度、相关风险、波动率与 VaR |

## 相比常见 AI 股票分析项目的精简

- 保留：核心股票研究、技术/基本面/事件分析、可视化报告。
- 精简：复杂机器人推送、多桌面端、多模型路由和大量部署配置。
- 强化：确定性评分、模型版本记录、来源证据、滚动回测和组合风控。
- 边界：这是研究辅助工具，不构成投资建议，也不会自动交易。

## 决策流程

```text
行情 / 财务 / 新闻
        ↓ 数据标准化与质量检查
确定性四因子评分（质量 / 趋势 / 事件 / 风险）
        ↓
证据链与 AI 解释（AI 不修改评分）
        ↓
历史信号校准与组合风险检查
        ↓
导出研究纪要，由用户独立决策
```

## 本地运行

需要 Node.js 22.13 及以上版本。

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```
